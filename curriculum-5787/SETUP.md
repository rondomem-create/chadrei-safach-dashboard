# חיבור אוטומטי לדשבורד תכניות לימודים ה׳תשפ״ז

דף הנחיתה הציבורי:
https://rondomem-create.github.io/chadrei-safach-dashboard/curriculum-5787/

## מה קיים כעת
- אתר ציבורי פתוח ללא שם משתמש, סיסמה או קוד.
- נתוני בסיס שנשאבו ב־25.10.2026: 14 כיתות, 26 מורים, 121 תכניות.
- כרגע מדובר ב**תמונת מצב**, ולא בנתונים שמתעדכנים ישירות מהמקור.

## חיבור עדכון חי — פעם אחת בלבד, מחשבון בעל הרשאה לקבצי המקור
1. היכנס ל־https://script.google.com/ דרך חשבון משרד החינוך שיש לו גישת עריכה או צפייה לקובצי תכניות הלימודים.
2. צור פרויקט חדש של **Google Apps Script**.
3. פתח את הקובץ [Code.gs](./backend/Code.gs), העתק את כל תוכנו אל הפרויקט והחלף את תכולת `Code.gs`.
4. שמור. בחר **Deploy → New deployment → Web app**.
5. תחת **Execute as** בחר **Me**. תחת **Who has access** בחר **Anyone** (לא "Anyone in organization"). 
6. פרוס, אשר את הרשאות הקריאה לספרדשיטים, והעתק את כתובת `/exec`.
7. הכנס את הכתובת למשתנה `DATA_ENDPOINT` בקובץ [index.html](./index.html), או מסור את כתובת `/exec` לעוזר כדי שיעדכן את האתר.

כך האתר הציבורי ישאב רק: כיתה, מורה, מקצוע, מספר השבועות, מספר השבועות שמולאו, מזהה לשונית וקישור למסמך המקור. **תוכן תכניות הלימודים, פרטי תלמידים ושדות אחרים לא מפורסמים.**

האתר מתרענן באופן אוטומטי כל 5 דקות ומציע כפתור רענון ידני; תוצאות הבקשות נשמרות ל־5 דקות ב־CacheService להפחתת עומס.

**חשוב:** אם משרד החינוך מגביל פריסה ציבורית של Apps Script, ייתכן שהאפשרות "Anyone" לא תופיע. במקרה כזה אין לפרסם את קובצי המקור כציבוריים כמעקף. יש להשתמש בשירות backend מאובטח אחר או לאשר פתרון במסגרת מדיניות המוסד.

לקובצי תכנית הלימודים עצמם ייתכן שעדיין תידרש כניסה לחשבון מתאים; רק דף המעקב הציבורי פתוח לצפייה ללא הרשאות.
